# Unified Agent Skills & Methodology (Karpathy + Superpowers + Understand-Anything + Skill-Creator)

## 1. Karpathy Principles (Caution & Simplicity)
- **Think Before Coding**: Never guess or hide confusion. Surface tradeoffs and ask when uncertain.
- **Simplicity First**: Minimum code that solves the problem. No overengineering.
- **Surgical Changes**: Touch only what you must. Do not touch unrelated code.

## 2. Superpowers Methodology (Structured Execution)
- **Brainstorm & Spec First**: Confirm architecture before jumping into coding.
- **Plan & Batch Tasks**: Break tasks into bite-sized, verifiable units.
- **Test-Driven Development (TDD)**: Write failing test -> make it pass -> refactor.
- **Systematic Debugging**: Trace root causes systematically.
- **Evidence-Based Verification**: Verify with live execution before claiming completion.

## 3. Understand-Anything Capabilities (Graph & Impact Analysis)
- **Knowledge Graph Visualization**: Analyze codebases and Karpathy LLM wikis into visual interactive graphs.
- **Diff Impact Analysis**: Inspect ripple effects across functions and modules before committing changes.
- **Guided Tours & Onboarding**: Walkthrough complex codebases step by step.

## 4. Skill Creator Capability (Meta Skill Authoring)
- **Skill Authoring & Benchmarking**: Automatically generate, evaluate, and optimize new custom skills upon request.
