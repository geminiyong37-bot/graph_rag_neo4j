2. 기금운용심의회 구성에 관한 사항(시행령 제14조의5 제2항 내지 제6항)

|  | Q 7. 반드시 대학교육기관에 두는 기금운용심의회의 위원장은 대학교육기관의 장으로 하고, 대학교육기관을 설치․경영하는 학교법인에 두는 기금운용심의회의 위원장은 학교법인의 이사장으로 하여야 하나요? |  |
| --- | --- | --- |
|  | ☞ 사립학교법 시행령 제14조의5 제2항에서 정한 바와 반드시 각각 기금운용심의회 위원장은 대학교육기관의 장, 이사장으로 하여야 합니다. 다만, 사립학교법 제14조의5 제6항에서는 기타 기금운용심의회의 구성에 필요한 사항은 기금운용심의회의 의결을 거쳐 기금운용심의회의 위원장이 정하도록 하고 있는 바, 대학교육기관의 장 또는 이사장이 궐위 상태이거나 위원장 직 수행이 부득이 불가능한 경우를 대비하여 기금운용심의회 의결을 거쳐 기금운영심의회 운영 및 구성에 관한 자체 규정 마련 등을 통해 직무 대행자 지정이 가능합니다. |  |

|  | Q 8. 기금운용심의회 위원으로 위촉할 수 있는 위원의 수는 어떻게 되나요? |  |
| --- | --- | --- |
|  | ☞ 기금운용심의회는 위원장 1명을 포함한 최대 7명까지 구성 가능하며, 사립학교법 시행령 제14조의 5 제4항 각 호에 해당하는 회계 또는 재무 관련 외부 전문가가 1명 이상을 반드시 포함하여 구성하여야 합니다. 그 외 교원, 직원, 학생, 외부 전문가, 동문 및 학교의 발전에 도움이 될 수 있는 사람에 해당하는 각 1인을 반드시 포함하여 위촉할 필요는 없으나, 기금운용심의회 설치 및 운영 취지를 고려하여 학교 또는 학교법인의 구성원을 대표할 수 있는 집단이 균등하게 포함될 수 있도록 노력해야 하며, 최소 위원의 정수는 위원장을 포함하여 5인 이상 7인 이하로 구성할 것을 권장합니다. |  |

|  | Q 9. 기금운용심의회 위원의 임기는 2년인데 연임이 가능한가요? |  |
| --- | --- | --- |
|  | ☞ 기금운용심의회 위원의 임기는 2년이며, 연임 및 중임 모두 가능합니다. |  |

3. 기금운용심의회 심의 사항(시행령 제14조의6 제1항)

|  | Q 10. 기 투자된 기금을 동일 상품 만기 후 재예치하는 경우 심의 사항인가요? |  |
| --- | --- | --- |
|  | ☞ 사립학교법 및 동법 시행령 시행(2018.5.29.) 이후 정기예금과 같이 원금의 손실 없는 상품에 단순 재예치하는 경우를 포함하여 법령 시행 전 운영하던 기금 운용에 변동 사항이 발생한 경우 심의운용심의회 구성 후 반드시 심의하여야 하며, 이 후 기 투자된 기금을 동일 상품 만기 후 재예치하는 경우에는 심의 필요 사항에 해당되지 않습니다. 다만, 최초 투자액 대비 자산의 감소 등 변동성이 고지된 위험관리 필요가 있는 상품에 신규 투자하거나 투자 조건 등을 변경하는 경우에는 반드시 심의운용심의회 심의를 거쳐야 합니다. |  |

|  | Q 11. 기금 투자 시 매번 기금운용심의회 심의 및 의결을 받아야 하나요? |  |
| --- | --- | --- |
|  | ☞ 기 투자된 동일 상품 만기 후 단순 재예치(Q10 참조) 등과 같은 경우에는 매번 심의 의결을 받을 필요는 없으나, 기금의 운용은 장기적인 투자계획에 기초하여 안정적으로 운용되어야 하므로 투자 수입 극대화를 위해 기금 운영에 관한 사항은 자금의 수급조건, 시장상황을 분석하여 허용 위험 수준을 설정하고 관리하는 차원에서 1년 단위로 검토, 심의하는 것을 원칙으로 운영하여야 합니다. |  |

|  | Q 12. 기금운용심의회 구성 및 운영에 관한 자체 규정 마련은 어떻게 하나요? |  |
| --- | --- | --- |
|  | ☞ 사립학교법 시행령 제14조의5 및 제14조의6에서 정하지 아니한 사항 중 기금운용심의회의 구성 및 운영에 필요한 사항은 기금운용심의회의 의결을 거쳐 기금운용심의회의 위원장이 자체적으로 규정 등을 마련하여 정할 수 있습니다. |  |

|  | Q 13. 기금운용심의회에서 심의사항의 범위는 어떻게 되나요? |  |
| --- | --- | --- |
|  | ☞ 「사립학교법 시행령」 제14조의6 제1항에 따라 기금운용심의회는 “매 회계연도 법 제32조의2제3항에 따른 기금운용의 계획에 관한 사항” 및 “기금 운용에 관한 지침 제정 및 개정”과 그 밖에 위원장이 심의가 필요하다고 인정하는 사항에 대해 심의를 거치도록 규정하고 있습니다. 기금운용의 계획에 관한 사항의 범위에는 기금운용과 관련하여 투자가능자산, 목표수익률, 위험관리기준, (장․단기)자산배분원칙 등에 대한 운용계획을 포함한 기금운용계획 중 주요한 지출금액의 변경 사항에 대한 심의 사항도 포함되며, [참고]로 제시한 기재부 기금 자산운용지침 작성 가이드라인을 참고하여 학교 및 학교법인의 기금운용계획은 내부 자산운용담당자가 업무에 활용할 수 있도록 상세하게 작성하는 것을 권장합니다.<br>【참고】기획재정부 기금 자산운용지침 작성 가이드라인(2018.1.) 중 「기금운용심의회 심의사항」<br>• 기본적인 기금운용정책방향 설정<br>• 중장기 및 연간 기금운용계획안의 작성<br>• 자산운용지침(투자정책서)의 제정 및 개정<br>• 기금운용계획 중 주요항목 지출금액의 변경<br>• 기금결산보고서의 작성<br>• 기금의 관리․운용에 관한 중요사항 및 기금관리주체가 필요하다고 인정하여 부의하는 사항 |  |
